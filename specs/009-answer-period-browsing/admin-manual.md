# 管理ユーザー向けマニュアル

## 現在の管理範囲

現時点では専用の管理者権限と管理画面はありません。管理用アカウントも一般ユーザーと同じGoogleログインを使用し、そのアカウント自身が作成したQuestionだけを管理できます。

## Questionを管理する

1. 管理に使用するGoogleアカウントでログインします。
2. `My Questions`を開きます。
3. Questionの状態、回答数、利用可能な操作を確認します。

| 状態 | 利用できる操作 |
| --- | --- |
| `DRAFT` | 編集、Review、公開 |
| `OPEN` | Question画面と回答数の確認 |
| `CLOSED` | 回答受付終了と、回答が引き続き非公開であることの確認 |
| `REVEALED` | Reveal後のAnswer閲覧 |

公開前に本文と締切を確認してください。Questionは任意の言語で記述でき、回答言語はPersonal Agentが本文から判断します。公開後はQuestionを編集できません。

## Answerを確認する

- `OPEN`および`CLOSED`では、Question作成者であっても他のユーザーのAnswerを閲覧できません。
- `REVEALED`では、Question画面からAnswerのExcerptと本文を確認できます。
- 回答数はHome、Question画面、`My Questions`で確認できます。

## 現在できない管理操作

- 他のユーザーが作成したQuestionの管理対象としての一覧表示・編集
- 公開済みQuestionの編集または削除
- 他のユーザーのAnswerの編集または削除
- ユーザーの停止、権限変更
- 管理ログの閲覧

不適切なQuestionやAnswerを管理画面から削除する機能は、現時点では提供されていません。
